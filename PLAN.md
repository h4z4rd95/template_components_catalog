> each one mixing a different framework, motion engine and 3D stack against a distinct aesthetic school.

## 1. Mission & Non-Negotiables

| Requirement | How it is enforced |
|---|---|
| **Everything is real, nothing is a placeholder** | Every variation compiles, renders, and is verified in a real browser build before it is checked off. |
| **Self-documenting** | Every variation is wrapped in a **Metadata HUD** (ID + name, tech stack, aesthetic vibe, interaction blueprint, source link). |
| **Scrollable showroom** | `docs/index.html` hub → filterable/searchable infinite catalog, lazy-mounted live iframes. |
| **Deployable to GitHub Pages** | `docs/` is a buildless static site (serves as-is). Framework apps are exported into `docs/framework/*` by CI. |
| **Local preview** | `npm run preview` → static server over `docs/` on `0.0.0.0:4173`. |
| **Iterative delivery** | One *Batch* per turn; each batch appends to `PROGRESS.md` and updates the dashboard below. |

**route generator** all read the same record. Add a variation once → it appears everywhere, with no drift.

**Rules of the matrix:** no two variations in the same batch repeat a `(framework, motion-engine, aesthetic)`
triple; at least one variation per batch must push a *raw* GPU technique (hand-written shader);
at least one must be achievable with **zero** 3D (proving restraint counts as style).

## 4. Definition of Done (every single variation)

1. Real, complete, typed implementation — no TODOs, no empty handlers, no "lorem" copy.
2. Fully responsive (≥360px → ≥2560px), fluid type via `clamp()`, no horizontal overflow.
3. `prefers-reduced-motion` honoured with a meaningful static composition (not a blank page).
4. Adaptive quality: DPR clamp + particle/segment budget from `qualityTier()`.
5. WebGL/RAF loops dispose correctly (geometry, material, renderer, listeners, observers).
6. Pointer-safe: no hover-only content; keyboard reachable controls; visible focus.
7. Wrapped in the Metadata HUD + registered in `catalog/catalog.json` (status bumped to `stable`).
8. Survives `npm run build` and renders inside the hub iframe without console errors.
9. Logged in `PROGRESS.md`.

### Known constraints / gotchas (read before resuming)
- `node_modules/`, `.next/`, `out/`, `dist/` are **not** snapshotted → after any interruption run
  `npm install` before building. `docs/framework/*` is generated by `npm run build` (CI does it too);
  the hub detects its absence and shows build instructions instead of a broken frame.
- **React must stay `~19.2.x`**: `@react-three/fiber@9.7` declares `react >=19 <19.3`. Bumping to 19.3
  breaks `npm install` (ERESOLVE). Never use `--legacy-peer-deps` to paper over it.
- `next/dynamic` options **must be inline object literals** — the compiler statically analyses the call
  and rejects a shared `options` variable.
- CSS Modules require **pure selectors**: `[data-tone="stone"]` alone is rejected; always scope to a
  local class (`.cell[data-tone="stone"]`).
- Backticks are illegal inside GLSL template literals in `packages/shared/src/glsl/*` — they terminate
  the string. Run `npm run typecheck` after touching a shader.
- **gsap.context scoping**: selector strings inside `gsap.context(fn, scopeEl)` are queried *within*
  `scopeEl`. Animating an element that lives outside the scope element silently does nothing — use a
  ref instead (this bit V02 once).
- Browser WebGL context budget (~8–16 live contexts) → the hub lazy-mounts iframes with an
  IntersectionObserver, caps at 6 concurrent frames and evicts the furthest before mounting another.
- GSAP 3.13+ ships SplitText/Observer free in the public npm package — no club membership needed.
