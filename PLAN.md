## 1. Mission & Non-Negotiables

| Requirement | How it is enforced |
|---|---|
| **Everything is real, nothing is a placeholder** | Every variation compiles, renders, and is verified in a real browser build before it is checked off. |

| **Iterative delivery** | One *Batch* per turn; each batch appends to `PROGRESS.md` and updates the dashboard below. |

### The metadata contract (why it matters)
`catalog/catalog.json` is the spine. The **hub cards**, the **React HUD**, the **Nuxt HUD** and the
**route generator** all read the same record. Add a variation once → it appears everywhere, with no drift.

  "id": "Hero_V01_KineticBrutalGrid",   // {Discipline}_{V##}_{StyleCodename}

**Rules of the matrix:** no two variations in the same batch repeat a `(framework, motion-engine, aesthetic)`
triple; at least one variation per batch must push a *raw* GPU technique (hand-written shader);
at least one must be achievable with **zero** 3D (proving restraint counts as style).

## 4. Definition of Done (every single variation)

1. Real, complete, typed implementation — no TODOs, no empty handlers, no "lorem" copy.
2. Fully responsive (≥360px → ≥2560px), fluid type via `clamp()`, no horizontal overflow.
3. `prefers-reduced-motion` honoured with a meaningful static composition (not a blank page).
4. Adaptive quality: DPR clamp + particle/segment budget from `qualityTier()`.
5. WebGL/RAF loops dispose correctly (geometry, material, renderer, listeners, observers).
6. Pointer-safe: no hover-only content; keyboard reachable controls; visible focus.
7. Wrapped in the Metadata HUD + registered in `catalog/catalog.json` (status bumped to `stable`).
8. Survives `npm run build` and renders inside the hub iframe without console errors.
9. Passes `npm run verify:browser` for its route: no console errors, no scrollable or clipped overflow at
   360/768/1440/2560, nothing hidden under the host chrome, HUD present, and a composed static frame
   under `prefers-reduced-motion`. **A variation is not “done” until its GIF exists in the vision reel.**
10. Logged in `PROGRESS.md`.

### Known constraints / gotchas (read before resuming)
- `node_modules/`, `.next/`, `out/`, `dist/` are **not** snapshotted → after any interruption run
  `npm install` before building. `docs/framework/*` is generated by `npm run build`; the hub detects its
  absence and shows build instructions instead of a broken frame.
- **React must stay `~19.2.x`**: `@react-three/fiber@9.7` declares `react >=19 <19.3`. Never paper over
  the ERESOLVE with `--legacy-peer-deps`.
- `next/dynamic` options **must be inline object literals** — the compiler statically analyses the call.
- CSS Modules require **pure selectors**: `[data-tone="stone"]` alone is rejected; scope to a local class.
- Backticks are illegal inside GLSL template literals in `packages/shared/src/glsl/*` — they terminate the
  string. Run `npm run typecheck` after touching a shader.
- **`gsap.context` scoping**: selector strings inside `gsap.context(fn, scopeEl)` are queried *within*
  `scopeEl`. Animating an element outside the scope silently does nothing — use a ref instead.
- **Layout traps that only a browser reveals** (all regression-guarded in `scripts/vision.mjs`):
  an author `display` rule defeating `hidden`; rotated sections widening scroll width; `max-content`
  implicit grid columns; content colliding with the 2.9rem host chrome band; desktop-only custom cursors
  rendering as stray marks on touch. Run `npm run verify:browser:audit` before claiming a variation works.
- **Long captures run detached** (20 min on a software rasterizer). Never in a foreground command.
- **Headless WebGL is a negotiation, not a constant.** A provisioned Chromium needs its SwiftShader/ANGLE
  libraries **beside the binary**, not merely in `lib/` + `LD_LIBRARY_PATH`: the GPU process inherits no
  environment, so ANGLE's lazy `dlopen` finds nothing and *every* context fails with
  `Internal Vulkan error (-3)` / `BindToCurrentSequence failed` — which reads exactly like "machine has no
  GPU". And `--use-angle=swiftshader` fails in some hardened containers where
  `--use-angle=vulkan --enable-features=Vulkan,VulkanFromANGLE` succeeds. `scripts/vision.mjs` now tries
  both profiles and records the winner (`gpuProfile` in `report.json`); `npm run setup:browser` proves
  graphics at provisioning time. **Never "fix" shader code for this class of failure.**
- GSAP 3.13+ ships SplitText/Observer free in the public npm package — no club membership needed.
