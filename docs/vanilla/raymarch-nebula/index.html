Blueprint

What one file can do when you skip the framework

Volume, not surfaces

The shader marches a ray per pixel through a 3D noise field, accumulating density and emission. There is no geometry at all — the nebula is a number that happens to look like a cloud.

Budgeted by device

Step count and render scale come from deviceMemory, hardware concurrency and DPR, then a frame watcher lowers them once if the budget is missed — the same policy the framework tracks use.

Pointer as a field modifier

Pointer position is smoothed into a 2D uniform that both tilts the ray direction and moves the light source, so the volume appears to churn rather than slide.

Three honest states

WebGL2, reduced motion, or no WebGL2 at all: each has a designed composition. A catalogue may never present a blank frame and call it art.

Zero network requests

No fonts, no scripts, no stylesheets — everything ships in this document. The metadata HUD reads the shared manifest when it can and falls back to the inline record when it cannot.

Metadata, in public

The HUD is the same contract as every other variation: ID, stack, vibe and a one-sentence interaction blueprint. Copying the ID gets you the exact variant name.
