A ring that opens, travels and closes

One JavaScript file, two consumers: this variation and the gaming-news blueprint in docs/sites/gaming-news/. One implementation — so the two cannot disagree about how a section menu behaves.

  • Opens on click, not hover: a menu that covers the page must not open by accident as the pointer crosses it.
  • The arc is placed with plain trigonometry and mirrored for RTL, so the ring sweeps with the reading direction, not against it.
  • Below 720 px the same items become a list: the honest phone answer, not a shrunken ring.
  • With prefers-reduced-motion the fade stays and the travel goes: the nav still works, it just does not fly.
